# Module 03 — Reading Data (SELECT)

`SELECT` asks the database for data — the **R** in CRUD (your `GET`). This module is
just *getting rows back*; **filtering** which rows comes next (Module 04).

## What you'll learn

- `SELECT * FROM table` — all columns
- `SELECT col1, col2 FROM table` — pick columns
- **Aliases** (`AS`) — rename columns in the output
- **Expressions** — compute values in the SELECT (`price * 2`)
- `DISTINCT` — unique values only

The `books` table from Module 02 drill 03 (12 rows). Recreate it if needed.

- **01-select-basics** — `*`, specific columns, aliases
- **02-expressions-and-distinct** — computed columns, DISTINCT
