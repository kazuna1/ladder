# Module 05 — Sorting & Limiting

Real APIs don't dump rows in random order — they **sort** and **paginate**. This is
the last piece of powerful reading.

## What you'll learn
- `ORDER BY` — sort results (`ASC` default, `DESC` to reverse)
- Sort by **multiple columns**
- `LIMIT` — cap how many rows
- `OFFSET` — skip rows (the basis of pagination / "page 2")

## Prereq
The `books` table (Module 02 drill 03).

## Drills
- **01-order-by** — sorting, ASC/DESC, multiple keys
- **02-limit-offset** — capping and paginating
