# Module 07 — Deleting (Delete)

`DELETE` removes rows — the **D** in CRUD. Same critical rule as UPDATE:
**always `WHERE`**, or you empty the whole table.

## What you'll learn
- `DELETE FROM table WHERE ...`
- `RETURNING *` — see what you removed
- `TRUNCATE` — wipe a whole table fast (and how it differs from DELETE)
- The **WHERE-or-disaster** rule (again — it matters most here)
- **Capstone:** a full Create→Read→Update→Delete lifecycle, no hints

## Prereq
The `books` table.

## Drills
- **01-delete-basics** — DELETE WHERE, RETURNING, TRUNCATE, the danger
- **02-crud-capstone** — the whole CRUD cycle end-to-end (the boss)

Say **"review"** after a drill. Finishing 02 means you've got SQL CRUD down.
