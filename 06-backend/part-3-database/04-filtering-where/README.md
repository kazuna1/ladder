# Module 04 — Filtering (WHERE)

**The most important word in SQL.** `WHERE` picks *which rows* — it's your `.find()`
and `.filter()`. Every "get one", every search, every targeted update/delete uses it.

## What you'll learn

- `WHERE column = value` — exact match
- Comparison operators — `>`, `<`, `>=`, `<=`, `<>` (not equal)
- Combining — `AND`, `OR`, `NOT`
- `IN (...)` — match any of a list
- `BETWEEN a AND b` — a range
- `LIKE` / `ILIKE` — pattern/text search (with `%` wildcards)
- `IS NULL` / `IS NOT NULL` — empty-check (NULL is special!)
